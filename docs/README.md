# Declutter

**안전한 테스트 기반 리팩토링을 위한 Claude Code 플러그인**

레거시 코드를 체계적으로 정리하고, 테스트로 동작을 보존하며, 원자적 변경으로 안전하게 리팩토링합니다.

---

## 5분 퀵스타트

### 1. 코드베이스 평가

```bash
/assess src/
```

코드 스멜, 복잡도 핫스팟, 리팩토링 기회를 식별합니다.

### 2. 리팩토링 시작

```bash
/declutter src/problematic-module.py
```

5단계 워크플로우가 자동으로 시작됩니다:
- 평가 → 계획 → 테스트 하네스 → 리팩토링 → 검증

### 3. 결과 확인

모든 테스트가 통과하고, 동작이 보존되며, 코드 품질이 개선됩니다.

---

## Iron Laws

Declutter는 세 가지 철칙을 따릅니다:

| 철칙 | 의미 |
|------|------|
| **평가 없이 리팩토링 금지** | 코드를 이해하기 전에 변경하지 않습니다 |
| **테스트 없이 코드 변경 금지** | 특성화 테스트로 동작을 먼저 캡처합니다 |
| **검증 없이 완료 선언 금지** | 모든 테스트 통과를 확인합니다 |

[Iron Laws 상세 →](concepts/iron-laws.md)

## 에이전트 시스템

Declutter는 전문화된 에이전트를 활용합니다:

| 에이전트 | 역할 | 모델 |
|----------|------|------|
| `declutter-analyzer` | 코드 분석 | Sonnet |
| `declutter-smell-detector` | 스멜 탐지 | Haiku |
| `declutter-executor` | 리팩토링 실행 | Sonnet |
| `declutter-reviewer` | 최종 검증 | Opus |
